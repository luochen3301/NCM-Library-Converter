NCM Library Converter V2.2

Windows 使用方法：

1. 解压 NCM-Library-Converter-V2.2-windows.zip。
2. 双击 NCM Converter.exe 启动。
3. 首次启动后选择音乐库文件夹。
4. 如需修改输出位置，请先进入“设置”页确认输出策略。
5. 扫描完成后点击“转换待处理”。

说明：

- 这是单文件桌面版，不需要用户手动安装 Python。
- 本地数据默认保存在 %APPDATA%\ncmdump\ncmdump.sqlite3。
- V2.2 新增转换完成摘要和失败分组，便于检查结果、复制错误、定位文件和重试失败项目。
- 语言分类实验页只基于本地文件名和目录文本，不联网查询。
- 新用户默认使用 Obsidian 深色主题；已有用户的主题设置会保留。
