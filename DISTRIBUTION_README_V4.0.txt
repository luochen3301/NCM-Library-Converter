NCM 音乐库转换器 V4.0 - Windows 便携版
================================================

使用方法
--------
1. 将整个 ZIP 解压到可写目录。
2. 双击 “NCM Converter.exe”。
3. 首次运行时选择音乐库文件夹。
4. 扫描完成后转换全部待处理项，或勾选指定文件转换。

升级说明
--------
- V4.0 使用 PySide6 + QML，不再依赖旧 PyQt6 Widgets 运行时。
- 数据库结构、设置字段和文件行为保持不变，可直接读取已有本地数据。
- 默认数据库位于：%APPDATA%\ncmdump\ncmdump.sqlite3
- 建议升级前保留一份重要音乐库和数据库备份。

FLAC 转 MP3
-----------
- 打开“工具 → FLAC→MP3”。
- 可拖放或选择单个文件、多个文件或文件夹。
- 可选 128/192/256/320 kbps、输出位置、保留目录结构和跳过已有 MP3。
- 原 FLAC 始终保留。

完整性校验
----------
- SHA256SUMS.txt 包含包内文件校验值。
- ZIP 同目录的 .sha256 文件包含压缩包自身校验值。

提示
----
- 如 Windows SmartScreen 提示未知发布者，可选择“更多信息”后继续运行。
- 本程序没有商业代码签名证书。
- 本工具仅用于你有权处理的本地音乐文件。
