NCM Library Converter V2.1

Windows 使用方法：

1. 解压 ncmdump-V2.1-windows.zip。
2. 双击 NCM Converter.exe 启动。
3. 首次启动后选择音乐库文件夹。
4. 如 Windows SmartScreen 提示未知发布者，请选择“更多信息”后继续运行。

说明：

- 这是单文件桌面版，不需要用户手动安装 Python。
- 本地数据默认保存在 %APPDATA%\ncmdump\ncmdump.sqlite3。
- V2.1 新增“语言分类 · 实验”页面，语言判断只基于本地文件名和目录文本，不联网。
- 新用户默认使用 Obsidian 深色主题；已有用户的主题设置会保留。
